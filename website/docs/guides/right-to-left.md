# Right to left

Every style uses logical properties, so a page lays out correctly the moment it is told its direction:

```pudu
Fui.page("Home", Theme.theme(), Catalog.blocks()).rightToLeft().language("ar")
```

Use the `Direction` component for one region. `fui doctor` reports a physical property in your own
components.
