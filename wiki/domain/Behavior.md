# Behavior

- **Definition:** A short optional script a [[domain/Block]] carries for what the platform cannot do
  declaratively. It ships only on pages that use the slot, and the component still works without it.
- **Holders:** context menu, command filtering, copy buttons, toast timing and swiping, and drawer
  dismissal.
